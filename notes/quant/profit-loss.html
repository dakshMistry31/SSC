Profit & Loss

SSC CHSL Quantitative Aptitude — Topic Notes

📖 1. Basic Terms

Cost Price (CP): Price paid to acquire an item.

Selling Price (SP): Price at which the item is sold.

If SP > CP, there is a profit. If SP < CP, there is a loss.

Profit = SP − CP
Loss = CP − SP

📈 2. Profit Percentage

Profit% = (Profit/CP) × 100
Example 1: CP ₹800, SP ₹920.
Profit = ₹120. Profit% = 120/800×100 = 15%.
Example 2: CP ₹1,500, SP ₹1,800.
Profit = ₹300. Profit% = 20%.
Example 3: CP ₹240, SP ₹300.
Profit = ₹60. Profit% = 60/240×100 = 25%.

📉 3. Loss Percentage

Loss% = (Loss/CP) × 100
Example 1: CP ₹1,000, SP ₹850 → Loss ₹150 → 15% loss.
Example 2: CP ₹600, SP ₹510 → Loss ₹90 → 15% loss.
Example 3: CP ₹2,500, SP ₹2,000 → Loss ₹500 → 20% loss.

🧮 4. Finding SP from CP and Profit/Loss

SP at p% profit = CP(100+p)/100
SP at l% loss = CP(100−l)/100
Example 1: CP ₹1,200, profit 15%. SP = 1200×115/100 = ₹1,380.
Example 2: CP ₹2,000, loss 12%. SP = 2000×88/100 = ₹1,760.
Example 3: CP ₹750, profit 20%. SP = 750×120/100 = ₹900.

🔄 5. Finding CP from SP

If profit = p%: CP = SP × 100/(100+p)
If loss = l%: CP = SP × 100/(100−l)
Example 1: SP ₹1,380 at 15% profit. CP = 1380×100/115 = ₹1,200.
Example 2: SP ₹1,760 at 12% loss. CP = 1760×100/88 = ₹2,000.

🏷️ 6. Marked Price and Discount

Marked Price (MP) is the listed price before discount.

Discount = MP − SP
Discount% = (Discount/MP) × 100
SP = MP(100−Discount%)/100
Example 1: MP ₹2,000 with 10% discount → SP = 2000×90/100 = ₹1,800.
Example 2: MP ₹1,500, SP ₹1,200 → Discount = ₹300 → 20%.
Example 3: MP ₹800 with 25% discount → SP = ₹600.

🧩 7. Combined Profit/Loss Situations

When multiple articles are involved, calculate total CP and total SP before finding the overall profit or loss percentage.

Overall profit% = (Total SP − Total CP)/Total CP × 100
Example 1: Two articles cost ₹500 and ₹700 and sell for ₹550 and ₹630. Total CP = ₹1,200; total SP = ₹1,180. Loss = ₹20 → 1⅔% loss.
Example 2: Articles cost ₹400 and ₹600 and sell for ₹480 and ₹660. Total CP = ₹1,000; total SP = ₹1,140 → 14% profit.

⚠️ 8. Common Mistakes

  • Calculating profit/loss percentage using SP instead of CP.
  • Confusing marked price with cost price.
  • Subtracting discount from CP when the discount is based on MP.
  • For multiple articles, averaging individual percentages without considering the cost-price weights.
