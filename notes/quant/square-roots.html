Square Roots

SSC CHSL Quantitative Aptitude — Topic Notes

📖 1. What is a Square Root?

The square root of a number is a value which, when multiplied by itself, gives the original number.

If x² = N, then √N = x

For example, √49 = 7 because 7 × 7 = 49.

Example 1: Find √144.
12 × 12 = 144, so √144 = 12.
Example 2: Which of 196, 200 and 225 are perfect squares?
196 = 14² and 225 = 15². Therefore 196 and 225 are perfect squares.
Example 3: Is 324 a perfect square?
18 × 18 = 324, so yes, 324 = 18².

🛠️ 4. Simplifying Square Roots

Factor the number into a perfect-square factor and the remaining factor.

√(ab) = √a × √b
Example 1: √72 = √(36×2) = 6√2.
Example 2: √180 = √(36×5) = 6√5.
Example 3: √200 = √(100×2) = 10√2.

📏 5. Estimating a Non-Perfect Square

Find the nearest perfect squares on either side.

Example 1: √50 lies between √49 = 7 and √64 = 8, so 7 < √50 < 8.
Example 2: √120 lies between √100 = 10 and √121 = 11, so 10 < √120 < 11.
Example 3: √70 lies between 8² = 64 and 9² = 81, so 8 < √70 < 9.

🧮 6. Useful Root Properties

√a × √b = √(ab)
√a / √b = √(a/b), for b > 0
(√a)² = a
Example 1: √3 × √12 = √36 = 6.
Example 2: √75 / √3 = √25 = 5.
Example 3: (√11)² = 11.

⚠️ 7. Common Mistakes

  • Thinking √(a+b) = √a + √b. This is generally false.
  • Forgetting to extract perfect-square factors.
  • Giving a decimal approximation when an exact simplified root is expected.
  • Confusing square with square root.
Remember: √(a+b) is not generally equal to √a + √b.

🔄 9. Quick Revision

  • √N is the number whose square is N.
  • Memorize common squares at least up to 20² for faster calculation.
  • Extract the largest perfect-square factor while simplifying.
  • For a non-perfect square, locate it between two consecutive perfect squares.
