Interest — Simple & Compound

SSC CHSL Quantitative Aptitude — Topic Notes

📖 1. Basic Terms

Principal (P): Original amount invested or borrowed.

Rate (R): Interest rate per year, usually expressed as a percentage.

Time (T): Duration for which money is invested or borrowed.

Amount (A): Principal + Interest.

🧮 2. Simple Interest

SI = (P × R × T)/100
Amount = P + SI
Example 1: Find SI on ₹5,000 at 8% p.a. for 2 years.
SI = 5000×8×2/100 = ₹800; Amount = ₹5,800.
Example 2: Find SI on ₹12,000 at 5% for 3 years.
SI = 12000×5×3/100 = ₹1,800.
Example 3: SI is ₹900 on ₹6,000 for 3 years. Find the rate.
R = 900×100/(6000×3) = 5%.

⏱️ 3. Time and Rate Variations

For simple interest, interest is directly proportional to P, R and T.

Example 1: If the principal doubles while rate and time stay fixed, SI doubles.
Example 2: If time changes from 2 to 5 years with everything else fixed, SI becomes 2.5 times.
Example 3: If rate falls from 10% to 8%, SI falls in the ratio 10:8 = 5:4.

📈 4. Compound Interest

In compound interest, interest is added to the amount at the end of each compounding period, so the next period's interest is calculated on the increased amount.

A = P(1 + R/100)ᵀ
CI = A − P
Example 1: ₹10,000 at 10% p.a. compounded annually for 2 years.
A = 10,000×1.1² = ₹12,100. CI = ₹2,100.
Example 2: ₹8,000 at 5% p.a. for 2 years.
A = 8000×1.05² = ₹8,820. CI = ₹820.

🔁 5. Compound Interest for Two Years

CI = P[(1+R/100)² − 1]
For two years, CI − SI = P(R/100)²
Example 1: P=₹5,000, R=10%, T=2. Difference = 5000×(10/100)² = ₹50.
Example 2: P=₹20,000, R=5%, T=2. Difference = 20,000×(0.05)² = ₹50.

📅 6. Half-Yearly Compounding

If interest is compounded half-yearly, use half the annual rate and twice the number of periods.

A = P(1 + R/200)^(2T)
Example: ₹10,000 at 10% p.a. compounded half-yearly for 1 year.
Rate per half-year = 5%; periods = 2. A = 10,000×1.05² = ₹11,025.

🛠️ 7. Comparing SI and CI

Simple InterestCompound Interest
Interest is calculated on original principal.Interest is calculated on accumulated amount.
SI = PRT/100.A = P(1+R/100)^T for annual compounding.
Grows linearly with time at a fixed rate.Grows through compounding.

⚠️ 8. Common Mistakes

  • Using the compound formula for a simple-interest question.
  • For half-yearly compounding, forgetting to halve the rate and double the number of periods.
  • Confusing interest with amount.
  • Using the percentage rate as a whole number instead of R/100 in formulas.
