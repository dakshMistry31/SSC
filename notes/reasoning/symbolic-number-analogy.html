Symbolic / Number Analogy

SSC CHSL General Intelligence & Reasoning — Topic Notes

📖 1. What is Symbolic / Number Analogy?

These questions use numbers, mathematical relationships or symbols to form an analogy. The task is to identify the operation or pattern connecting the first pair and apply it to the second pair.

A : B :: C : ? → identify the numerical/symbolic rule from A to B and apply it to C.

🎯 2. What You Need to Learn

  • Addition and subtraction relationships
  • Multiplication and division relationships
  • Squares, cubes and other powers
  • Digit-based relationships
  • Simple combinations of operations
  • Symbol replacement and coded operations

🛠️ 3. Method

  1. Check simple operations first: +, −, ×, ÷.
  2. Then check square/cube or multiplication by a constant.
  3. Check digit sum/product if direct arithmetic does not fit.
  4. Apply exactly the same rule to the second number.
Tip: Prefer the simplest rule that explains the given pair unless the options force a more specific pattern.

➕ 4. Addition / Subtraction Pattern

Example 1: 8 : 13 :: 15 : ?
8 + 5 = 13, so 15 + 5 = 20.
Example 2: 21 : 16 :: 30 : ?
21 − 5 = 16, so 30 − 5 = 25.
Example 3: 14 : 23 :: 19 : ?
14 + 9 = 23, so 19 + 9 = 28.

✖️ 5. Multiplication / Division Pattern

Example 1: 7 : 35 :: 9 : ?
7×5 = 35, so 9×5 = 45.
Example 2: 48 : 8 :: 72 : ?
48÷6 = 8, so 72÷6 = 12.
Example 3: 12 : 48 :: 15 : ?
12×4 = 48, so 15×4 = 60.

² 6. Square / Cube Pattern

Example 1: 5 : 25 :: 7 : ?
5² = 25, so 7² = 49.
Example 2: 3 : 27 :: 4 : ?
3³ = 27, so 4³ = 64.
Example 3: 6 : 36 :: 9 : ?
6² = 36, so 9² = 81.

🔢 7. Digit-Based Relationships

Example 1: 24 : 6 :: 35 : ?
2+4 = 6; therefore 3+5 = 8.
Example 2: 23 : 6 :: 41 : ?
2×3 = 6; therefore 4×1 = 4.
Example 3: 42 : 2 :: 93 : ?
4−2 = 2; therefore 9−3 = 6.

⚠️ 8. Common Mistakes

  • Using a different operation for the second pair.
  • Ignoring the order of digits.
  • Assuming a square/cube pattern when a simpler operation fits.
  • Overcomplicating a basic numerical relationship.
