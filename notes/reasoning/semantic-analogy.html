Semantic Analogy

SSC CHSL General Intelligence & Reasoning — Topic Notes

📖 1. What is Semantic Analogy?

Semantic analogy questions test whether you can identify the relationship between two words and apply the same relationship to another pair.

A : B :: C : ? → Find the relationship between A and B, then apply it to C.

The relationship may be based on place, function, profession, object, cause-effect, part-whole, degree, synonym/antonym, or another clear association.

🎯 2. What You Need to Learn

  • Identify the exact relationship in the first pair.
  • Apply the same relationship in the same direction.
  • Distinguish close but incorrect relationships.
  • Handle profession-place, object-function, part-whole and cause-effect relationships.
  • Solve quickly without being distracted by superficial similarities.

🛠️ 3. A Reliable Method

  1. Read the first pair.
  2. Express the relationship in a short sentence.
  3. Check whether that sentence works for the second pair.
  4. Choose the option that preserves the same relationship and direction.
Direction matters: “Doctor : Hospital” is not the same relationship as “Hospital : Doctor” if the question expects the original direction.

✏️ 4. Common Relationship Types

Profession → Workplace

Example 1: Doctor : Hospital :: Teacher : ?
Doctor works in a hospital; a teacher works in a school.
Example 2: Chef : Kitchen :: Judge : ?
A chef works in a kitchen; a judge works in a court.
Example 3: Pilot : Airport :: Librarian : ?
The relationship is profession to associated workplace/location. The answer is Library.

Object → Function

Example 1: Pen : Write :: Knife : ?
A pen is used to write; a knife is used to cut.
Example 2: Thermometer : Temperature :: Scale : ?
A thermometer measures temperature; a scale measures weight.
Example 3: Camera : Photograph :: Microphone : ?
A camera records photographs; a microphone records sound.

Part → Whole

Example 1: Wheel : Car :: Page : ?
A wheel is a part of a car; a page is a part of a book.
Example 2: Finger : Hand :: Toe : ?
A finger is part of a hand; a toe is part of a foot.
Example 3: Chapter : Book :: Department : ?
A chapter belongs to a book; a department belongs to an organization.

Cause → Effect

Example 1: Fire : Smoke :: Rain : ?
Fire can produce smoke; rain can produce water accumulation.
Example 2: Exercise : Fitness :: Study : ?
Exercise can improve fitness; study can improve knowledge.

⚠️ 5. Common Mistakes

  • Choosing an option that is related to the first word but not in the same relationship.
  • Ignoring the direction of the relationship.
  • Using a broad association when a more specific relationship exists.
  • Overthinking an analogy that has a direct functional relationship.

🔄 7. Quick Revision

  • Find the relationship first; look at options second.
  • Keep the same direction: A relates to B in the same way C relates to ?.
  • Common patterns: workplace, function, part-whole, cause-effect, degree, synonym/antonym.
